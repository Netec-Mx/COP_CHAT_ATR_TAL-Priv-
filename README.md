# COPILOT CHAT EN ATRACCIÓN Y DESARROLLO DE TALENTO

Este seminario está diseñado para transformar los procesos de adquisición de talento y desarrollo organizacional mediante el uso de IA. El programa abarca desde la optimización del sourcing y la automatización del filtrado curricular, hasta el diseño instruccional personalizado para planes de onboarding y la retención del talento clave utilizando analítica de datos.

## Estructura

- `CapituloXX/README.md`: guía de laboratorio por capítulo.

## Lista de laboratorios

### Capítulo 1

- [Generación de descriptivos de puesto y prompts de búsqueda para candidatos.](Capitulo01/README.md#generación-de-descriptivos-de-puesto-y-prompts-de-búsqueda-para-candidatos)
  - Descripción: Aplicar Copilot para elaborar descriptivos de puesto y construir prompts de búsqueda alineados con estrategias de atracción.
  - Duración estimada: 60 min

### Capítulo 2

- [Simulación de screening curricular y creación de scorecards de selección.](Capitulo02/README.md#simulación-de-screening-curricular-y-creación-de-scorecards-de-selección)
  - Descripción: Aplicar IA para evaluar CVs y construir scorecards de selección.
  - Duración estimada: 90 min

### Capítulo 3

- [Estructuración de la matriz de habilidades, DNC y planes de capacitación por puesto.](Capitulo03/README.md#estructuración-de-la-matriz-de-habilidades-dnc-y-planes-de-capacitación-por-puesto)
  - Descripción: Crear matrices de habilidades y planes de capacitación utilizando el contenido del capítulo.
  - Duración estimada: 90 min

### Capítulo 4

- [Creación de tablero de control de ejecución, seguimiento e indicadores de capacitación.](Capitulo04/README.md#creación-de-tablero-de-control-de-ejecución-seguimiento-e-indicadores-de-capacitación)
  - Descripción: Crear un tablero de control para seguimiento e indicadores de capacitación basado en el capítulo.
  - Duración estimada: 60 min
